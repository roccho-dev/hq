# Session row v1

## Purpose

`session.v1` is a replaceable run-index projection. It makes shell, Herdr, Codex, and Claude runs listable through one row shape while keeping append-only instruction and result rows as evidence authority.

A session row is not an execution command and is not a second event authority.

## Row shape

| key | required | type | source |
|---|---:|---|---|
| `version` | yes | string | Exactly `session.v1`. |
| `run_id` | yes | non-empty string | Result rows. |
| `instruction_id` | yes | non-empty string | Result rows. |
| `target` | yes | string | Instruction/result rows. |
| `status` | yes | status string | Latest valid result event. |
| `cwd` | yes | non-empty string | Instruction payload, default `.`. |
| `started_at` | yes | RFC3339 UTC string | First result event time. |
| `last_event_at` | yes | RFC3339 UTC string | Latest result event time. |
| `native_session_id` | no | non-empty string | Adapter result metadata. |
| `final_path` | no | non-empty string | Completed result `final.path`. |

Unknown fields fail validation in v1.

## Projection rule

For each `run_id`:

1. Validate the linked instruction and all result rows.
2. Order result rows by `seq`.
3. Project `status` from the latest event using the shared status taxonomy.
4. Copy immutable identity fields.
5. Preserve `native_session_id` when emitted.
6. Preserve a completed `final.path` as `final_path`.

The projection may be rebuilt from instruction and result JSONL. If a stored session row disagrees with valid source rows, the stored projection is stale and must not override source evidence.

## Retry rule

Retry does not move a terminal run back to `queued`. It creates a new instruction and a new `run_id`; `reply_to` links the new instruction to the prior instruction. This preserves attempt history and avoids state rewinds.
